# Baby Puzzle World

Автономная детская игра-пазл на Flutter.

## Первая версия
- 7 тематических миров и 16 пазлов.
- Перетаскивание четырёх деталей на поле 2×2.
- Награды-звёздочки и локальное сохранение прогресса.
- Все уровни открыты сразу.
- Нет рекламы, подписок и сетевых запросов; игра рассчитана на офлайн-режим.

Иллюстрации в первой сборке представлены встроенными emoji-глифами, поэтому дополнительные ресурсы не загружаются.

## Сборка
`flutter create --platforms=android --project-name baby_puzzle_world .`
`flutter pub get`
`flutter build apk --release`

APK: `build/app/outputs/flutter-apk/app-release.apk`.
